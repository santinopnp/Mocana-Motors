# Sistema de diseño Mocana Motors (copia local)

Copia del sistema publicado en https://claude.ai/artifact/8Kxmivv8zeaxByWGkLf5Rk (versión 1792196518-ace5).

- `index.js` — componentes React (`Button`, `TopBar`, `ProductCard`…), fuente de `components/bundle.js`.
- `bundle.css` — estilos de los componentes (clases `mm-`).
- `tokens.json` — colores, tipografía, espacios; `tokens.css` se genera desde este archivo.
- `icons.json`, `logos.json`, `fonts/` — íconos, logos y tipografías del sistema.

Para actualizar, vuelve a copiar estos archivos desde el sistema; no los edites aquí.
